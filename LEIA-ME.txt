# Missões Curtas

Aplicação para telemóvel. Não precisa de loja nem de internet depois de aberta a primeira vez (a voz usa o telemóvel).

## Como pôr no ecrã inicial

1. Envia a pasta para o telemóvel, ou abre o ficheiro index.html no Chrome / Safari.
2. Android (Chrome): menu ⋮ → Adicionar ao ecrã inicial / Instalar aplicação.
3. iPhone (Safari): partilhar → Adicionar ao Ecrã Principal.

Cada missão tem 5 passos. As estrelas ficam guardadas no telemóvel.
